Orchard Field Manager

Full-stack field operations system for McDougall Family Farming, Wenatchee Valley. Migrated from Make.com/Airtable to a self-hosted Node.js + PostgreSQL backend on Railway. Workers log irrigation sessions via NFC tags — tap to start, tap to end. Auto-calculates real hours, sets completed, and official hours (sets × 12h) on session close. Live timer with set counter visible during active sessions. Boss dashboard with Today view for nightly verification. Weather alerts at 88°F/90°F trigger fogger recommendations. Offline-capable PWA with session persistence and exponential backoff retry.
